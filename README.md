# Word Counter Desktop

**A modern, lightweight and offline-friendly desktop application for counting words, characters and managing text documents.**

Word Counter Desktop is a productivity tool designed to help students, writers, content creators, professionals and everyday users analyse and manage written content easily.

## Features

- **Word Counting:** Instantly count words in your text.
- **Character Counting:** View total characters, including spaces.
- **Sentence & Paragraph Counting:** Analyse your written content.
- **Reading Time:** Estimate how long it takes to read your text.
- **Speaking Time:** Estimate presentation and speaking duration.
- **Multiple Documents:** Create and manage multiple text documents.
- **Auto Saving:** Keep your work saved locally.
- **Undo Support:** Restore previous changes.
- **Export:** Print or save your documents as PDF.
- **Voice Typing:** Use speech recognition where supported.
- **Read Aloud:** Listen to your written content.
- **Language Support:** English and French.
- **Dark & Light Modes:** Choose your preferred appearance.
- **Offline Access:** Use the desktop application without an internet connection for core features.
